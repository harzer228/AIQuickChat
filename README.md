# AI Quick Chat

**[🇷🇺 Русский](README.md)** | **[🇬🇧 English](README.en.md)**

[![CI](https://github.com/harzer228/AIQuickChat/actions/workflows/ci.yml/badge.svg)](https://github.com/harzer228/AIQuickChat/actions/workflows/ci.yml)

Быстрый **desktop AI-ассистент для Windows**. Вызывается глобальной горячей
клавишей (`Ctrl+Space` по умолчанию) поверх любого приложения — браузера,
игры, редактора, проводника. Позволяет задать вопрос, вставить изображение из
буфера обмена (`Ctrl+V`) или прикрепить файл, и получить ответ от DeepSeek
(через OpenAI-совместимый RouterAI endpoint) с анализом изображений через
Cloudflare Vision. Умеет **диктовать сообщения голосом локально** (Speech-to-Text
на Vosk, без отправки аудио в интернет).

```
        Ctrl + Space
             ↓
      ┌─────────────┐
      │   AI Chat   │   ← минималистичное floating-окно
      │  Message... │
      └─────────────┘
             │
             ▼
         DeepSeek
             │
             ▼
           Ответ
```

```
  Ctrl + V (изображение)
        ↓
   Image Preview
        ↓
  Cloudflare Vision  ──→ описание изображения
        ↓
        DeepSeek      ──→ финальный ответ
```

## Возможности

- **Глобальная горячая клавиша** (по умолчанию `Ctrl+Space`) через WinAPI
  `RegisterHotKey` — работает в любом приложении, повторное нажатие скрывает окно.
  Опция «Открывать новую вкладку по горячей клавише» (по умолчанию включена)
  создаёт чистую вкладку при каждом вызове. Отдельная вторая клавиша
  **Speech-to-Text shortcut** (по умолчанию `Ctrl+Shift+Space`) открывает чат
  и сразу запускает голосовую диктовку.
- **Speech-to-Text (Vosk)**: локальное распознавание речи в отдельном потоке —
  голос не покидает компьютер. Кнопка микрофона слева от кнопки отправки
  запускает/останавливает диктовку, распознанный текст попадает в поле ввода.
  Автоматическая остановка по тишине (по умолчанию 1.5 сек), выбор микрофона,
  путь к модели Vosk и включение/выключение настраиваются в Settings.
- **Без рамки Windows**: полупрозрачное, скруглённое, всегда поверх окон.
- **Streaming-ответы** — текст появляется постепенно и **без подтормаживаний
  окна**: чанки буферизуются, отрисовка обновляется фиксированными порциями,
  поэтому интерфейс остаётся отзывчивым даже при длинных ответах. Во время
  генерации кнопка отправки превращается в **Stop** (квадратная) и реально
  прерывает запрос, сохраняя уже полученный текст.
- **Web Search**: переключатель в чате ищет актуальную информацию в интернете,
  передаёт очищенный контекст DeepSeek и показывает кликабельные источники
  в ответе. Провайдеры: Tavily / SearXNG / Serper / Brave **и «Local (no API)»** —
  локальный поиск без ключей и сторонних сервисов (модуль `local_websearch/`,
  каскад DuckDuckGo → SearXNG → Wikipedia + загрузка текста найденных страниц).
  ИИ может разбить вопрос на **несколько разных поисковых запросов** (мультипоиск)
  и объединить найденные источники; в настройках мультипоиск включается/выключается
  и ограничивается лимитом запросов (1–5).
- **Память ИИ**: в настройках можно указать информацию о себе или персональный
  промт — ИИ учитывает его в каждом ответе (включается/выключается чекбоксом).
- **Контекстное меню сообщений** (ПКМ): «Копировать» (рабочая кнопка),
  «Изменить» последнее своё сообщение — доступно даже после ответа ИИ: старый
  ответ удаляется, а ИИ отвечает уже на отредактированную версию (при правке
  можно прикладывать файлы, как в обычном чате); «Удалить» своё сообщение
  (ответ ИИ сохраняется) или ответ ИИ.
- **Вставка изображений** через `Ctrl+V`, кнопку прикрепления или
  **перетаскиванием прямо в окно чата** (PNG/JPG/JPEG/WEBP/BMP) с предпросмотром
  и кнопкой удаления; перетаскивать можно и текстовые файлы/документы.
  Отправленная картинка показывается в чате (миниатюра).
- **Vision pipeline**: изображение → Cloudflare Vision (`@cf/meta/llama-3.2-11b-vision-instruct`)
  → описание → DeepSeek → ответ. DeepSeek не получает само изображение.
  При первом использовании модели автоматически принимается лицензия Meta
  (запрос `prompt: "agree"`), ручное действие не требуется.
- **Вкладки чата**: кнопка `+` создаёт новую вкладку, у каждой вкладки своя
  история; вкладки закрываются красным крестиком внутри вкладки и сохраняются
  при включённом "Remember chat history".
- **Прикрепление текстовых файлов** (`.txt .py .js .html .css .json .md .csv .log`)
  с лимитом размера.
- **Настройки** в двух разделах (General / API) с проверкой соединения
  (`Test Connection`) для всех API.
- **Хранение API-ключей** в Windows Credential Manager (с fallback на
  обфусцированную копию в config.json).
- **Продолжение диалога** — контекст сохраняется в памяти до закрытия чата.
- **Автозапуск с Windows**, **запоминание истории**, **закрытие в трей**
  (окно всегда сворачивается в трей — приложение продолжает работать в фоне).
- **Горячая клавиша до 4 клавиш** (например `Ctrl+Alt+Shift+Q`).
- **Тёмная/светлая/системная тема** + 8 готовых палитр (Nord, Dracula, Solarized,
  Rosé Pine, Catppuccin, Tokyo Night, Everforest, Gruvbox) с цветными свотчами
  в настройках; регулируемая прозрачность окна.
- **Локализация**: English / Русский (по умолчанию определяется по языку Windows).
- **Анимации**: плавное открытие/закрытие окна (прозрачность + масштаб), появление
  сообщений, переход Send↔Stop, переключение вкладок и разделов настроек.

## 1. Установка Python

Скачайте и установите **Python 3.11+** (рекомендуется 3.12/3.13) с
https://www.python.org/downloads/

Во время установки обязательно отметьте галочку **"Add Python to PATH"**.

Проверьте установку:

```bash
python --version
```

## 2. Виртуальное окружение

```bash
cd AIQuickChat
python -m venv .venv
```

Активируйте окружение (Windows PowerShell):

```powershell
.\.venv\Scripts\Activate.ps1
```

(Если PowerShell запрещает скрипты — выполните один раз
`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` или активируйте через
`cmd` командой `.\.venv\Scripts\activate.bat`.)

## 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

Зависимости: `PySide6`, `httpx`, `Pillow`, `pytablericons` (иконки интерфейса),
`vosk` + `sounddevice` + `numpy` (локальное распознавание речи).
При установке на Python 3.11–3.13 всё ставится автоматически. Если на Python 3.14
сборка `pygame` (зависимость `pytablericons`) не проходит — выполните установку
`pytablericons` без зависимостей: `pip install --no-deps pytablericons`.

## 4. Запуск

```bash
python main.py
```

При первом запуске окно чата появится в центре экрана. Вызвать/скрыть его —
`Ctrl+Space`. Пока приложение работает, в системном трее есть иконка с меню
(Показать/Скрыть, Новый чат, Настройки, Выход).

## 5. Где указать RouterAI API key

Откройте **Настройки** (кнопка `⚙` в правом верхнем углу окна чата, либо меню
трея) → раздел **AI Providers**:

- **API URL** — по умолчанию `https://routerai.ru/api/v1`
- **API Key** — ваш ключ RouterAI
- **Model** — по умолчанию `deepseek/deepseek-v4-flash-0731`

Нажмите **Test Connection**, чтобы проверить.

## 6. Где указать Cloudflare Account ID

**Настройки** → **Vision AI** → поле **Cloudflare Account ID**.

Account ID можно найти в панели Cloudflare на странице Workers & Pages
(правая колонка, раздел "Account ID").

## 7. Где указать Cloudflare API Token

**Настройки** → **Vision AI** → поле **Cloudflare API Token**.

Токен создаётся в Cloudflare Dashboard → **My Profile** → **API Tokens** →
**Create Token**. Для работы с моделями Workers AI нужен токен с permission
**Workers AI: Run**. Также подойдёт глобальный API-ключ в формате `key:...`.

Модель Vision (по умолчанию `@cf/meta/llama-3.2-11b-vision-instruct`) можно
заменить на любую другую Vision-модель Cloudflare.

## 8. Как работает Vision pipeline

1. Пользователь вставляет/прикрепляет изображение (появляется предпросмотр).
2. При отправке изображение **кодируется в base64** и отправляется в
   Cloudflare Workers AI:
   `POST https://api.cloudflare.com/client/v4/accounts/{account_id}/ai/run/{model}`
   с телом `{"image": "<base64>", "prompt": "..."}`.
3. Cloudflare возвращает детальное **текстовое описание** изображения.
4. Описание (вместе с вопросом пользователя) передаётся в **DeepSeek** как
   обычное текстовое сообщение.
5. DeepSeek формирует финальный ответ.

Обычный текстовый чат (без изображения) Cloudflare **не вызывает** — лишние
запросы не отправляются.

Код Cloudflare-клиента изолирован в `api/vision.py` и легко заменяется.

## 8.1. Web Search

В **Настройки** → **Web Search**:

- **Enable Web Search** — включать поиск по умолчанию (переключатель также есть
  в чате рядом с полем ввода).
- **Provider** — `Tavily`, `SearXNG`, `Serper (Google)`, `Brave Search`.
- **Search API URL** — endpoint поискового сервиса (заполняется автоматически
  при выборе провайдера).
- **Search API Key** — хранится в Windows Credential Manager, как остальные ключи.
- **Maximum results** (1–20) и **Search timeout** (5–120 сек).
- **Multiple search queries** + **Max queries** (1–5) — мультипоиск: ИИ сам
  разбивает вопрос на несколько различных поисковых запросов, выполняет их
  последовательно и объединяет найденные источники (дубликаты по URL убираются).
- Кнопка **Test Connection** выполняет настоящий минимальный запрос и показывает
  `✓ Connected successfully` либо конкретную причину ошибки (например, текст из
  ответа API). Секретный ключ никогда не выводится целиком — только в виде
  `API key: tvly-****abcd`.

### Tavily

Интеграция использует актуальный официальный формат Tavily API:
`POST https://api.tavily.com/search` с авторизацией через заголовок
`Authorization: Bearer <API key>` (легаси-передача ключа полем `api_key` в теле
JSON не используется — именно она была причиной `HTTP 403`). Ошибки API
диагностируются по реальному тексту из ответа (`detail.error`), коды различаются:
`401` — авторизация, `403` — доступ/лимиты, `429` — превышение частоты,
`432`/`433` — лимиты плана/PayGo, `5xx` — ошибка сервера.

### Tavily MCP

Официальный Tavily MCP server был рассмотрен, но **не интегрирован**:
он требует запуска внешнего MCP-процесса (`npx`/`uvx`), асинхронного MCP-клиента
и зависимости `mcp`/`anyio`, которые пришлось бы связывать с синхронным
QThread-воркером приложения — это ненадёжные костыли ради одного HTTP-запроса.
Поэтому используется исправленный прямой REST-вызов Tavily. Логика поиска
изолирована в `api/web_search.py` и легко заменяется.

Как работает при включённом поиске:

```text
Пользователь
     ↓
DeepSeek решает, нужна ли актуальная информация
     ↓ (если да — до N разных запросов, мультипоиск)
Web Search (реальный HTTP-поиск по каждому запросу)
     ↓
Очистка результатов → дедупликация → структурированный контекст
     ↓
DeepSeek → ответ
     ↓
В ответе показываются кликабельные Sources
```

Используются только реальные результаты поиска; при ошибке или пустом ответе
приложение показывает сообщение (с реальной причиной и маскированным ключом) и
продолжает обычный чат без сбоя.

## 9. Как изменить горячую клавишу

**Настройки** → **Hotkey** → **Change** → нажмите желаемую комбинацию
(например `Alt+Space`, `Ctrl+Alt+Q`, `F8`, `Ctrl+Alt+Shift+Q`) → нажмите
**Enter** для подтверждения → **Сохранить**.

В том же разделе настраивается **Speech-to-Text shortcut** — отдельная глобальная
клавиша, которая открывает окно чата и сразу включает диктовку
(по умолчанию `Ctrl+Shift+Space`).

Приложение проверяет конфликты (комбинация уже занята системой) и не
принимает некорректные значения (например, одиночную клавишу без модификатора).

## 9.1. Speech-to-Text (диктовка)

Распознавание речи полностью **локальное** (Vosk) — аудио никуда не отправляется.

### Подготовка

1. **Настройки** → **Speech-to-Text** → включите **Enable Speech-to-Text**.
2. Скачайте модель Vosk (например `vosk-model-small-ru-0.22` или
   `vosk-model-small-en-us-0.15`) с https://alphacephei.com/vosk/models и
   распакуйте её в любую папку. Приложение **не скачивает** модель само.
3. Укажите путь к папке модели через **Browse...**.
4. При желании выберите конкретный **Microphone** из реальных устройств Windows
   и задайте **Silence timeout** (по умолчанию 1.5 сек — запись сама останавливается,
   когда пользователь замолчал).
5. Нажмите **Сохранить**.

### Использование

- Кнопка микрофона 🎤 **слева от кнопки отправки** — включить/остановить диктовку.
- Во время записи кнопка становится квадратной кнопкой остановки, внизу
  показывается статус `Listening...`.
- Распознанный текст автоматически появляется в поле ввода. Отправляйте его
  обычной кнопкой отправки (Enter).
- Можно диктовать и через глобальную клавишу **Speech-to-Text shortcut**
  (см. выше) — окно откроется и диктовка начнётся сразу.
- Если выбранный микрофон исчез из системы — приложение автоматически использует
  системный микрофон по умолчанию и показывает предупреждение в чате.

## 10. Как собрать `.exe`

В репозитории есть готовый spec-файл со всеми настройками (onefile, без консоли,
иконка, бандл `locales/` и иконок Tabler):

```bash
pip install pyinstaller
pyinstaller AIQuickChat.spec --noconfirm
```

Готовый файл появится в `dist\AIQuickChat.exe`.

Ручная сборка без spec (без переводов в бандле — используйте spec):

```bash
pyinstaller --noconsole --onefile --name AIQuickChat --icon icon.ico main.py
```

> Примечание: при первом запуске антивирус может ругаться на однофайловую
> сборку — это известная особенность PyInstaller. Добавьте файл в исключения,
> либо соберите с `--onedir`.

## 11. Разработка и тесты

```bash
pip install -r requirements.txt -r requirements-dev.txt
pytest            # все тесты (offscreen Qt, без сети и микрофона)
pytest --cov      # с отчётом покрытия
ruff check .      # линтер
```

Тесты живут в `tests/` и полностью офлайн: парсеры локального поиска
прогоняются на HTML-фикстурах, GUI — в режиме `QT_QPA_PLATFORM=offscreen`
с изолированным `%APPDATA%`. CI (GitHub Actions, `.github/workflows/ci.yml`)
запускает линтер и тесты на Python 3.11/3.12 при каждом push/PR.

Хуки pre-commit (опционально): `pre-commit install` (см.
`.pre-commit-config.yaml` — ruff, трейлинг-пробелы, проверки форматов).

## Настройки приложения

- **Theme**: Dark / Light / System.
- **Window opacity**: 60–100%.
- **Show animations**: плавное появление/скрытие окна.
- **Start with Windows**: автозапуск через реестр
  (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`) — без прав админа.
- **Remember chat history**: диалог восстанавливается при следующем запуске.
- **Close to tray**: крестик скрывает окно в трей (иначе завершает приложение).
- **Speech-to-Text** (раздел в Settings): включение/выключение распознавания,
  выбор микрофона из реальных устройств Windows, тайм-аут тишины (0.5–5.0 сек),
  путь к локальной модели Vosk с кнопкой выбора папки.

## Безопасность

- Ключи **не захардкожены**: они хранятся в Windows Credential Manager.
- Данные отправляются **только** в те API, которые настроил сам пользователь
  (RouterAI / OpenAI-compatible и Cloudflare AI).
- Нет телеметрии, рекламы и скрытых сетевых запросов.
- Локальный поиск (`local_websearch/`) обращается только к бесплатным публичным
  поисковым сайтам и Википедии; папку можно просто удалить — пункт «Local»
  исчезнет из настроек.
